## Current Summary

The compact summary is generated by:

```bash
python inference/summarize_tma24_sam3_results.py
```

Output files:

```text
output/tma24_sam3_results_summary.csv
output/tma24_sam3_results_summary.md
```

Current high-level readout:

- Medical-SAM3 and base SAM3 both have usable signal with whole-image box prompts.
- Text-only prompts are weak for these pathology labels.
- Cross-region transfer is near zero, so the model is not reliably generalizing from one prompted region to a held-out region.
- Dense point proposals mostly over-cover the image.
- Dense box proposals are more useful as oracle-style proposals, but this is whole-image search, not generalization.
