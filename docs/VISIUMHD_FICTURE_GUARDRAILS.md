# VisiumHD Exp1 Official FICTURE Guardrails

These checks are mandatory before submitting or reporting any FICTURE-dependent
candidate-pool, ranking, VLM judge, or direct-grounding result for VisiumHD
Exp1.

## Official Pipeline

Run the official renderer:

```bash
python3 inference/visium_hd_exp1/render_official_filtered_ficture_he_map.py
```

Official outputs are written to:

```text
output/visium_hd_exp1/ficture_official_filtered_he_aligned/
```

The canonical files are:

- `filtered_ficture_official_full_he_canvas.png`
- `filtered_ficture_official_overlay_on_he.png`
- `filtered_ficture_official_qc_triptych.png`
- `summary_official.json`

`summary_official.json` must say `PASS_OFFICIAL` before any downstream result
is reported.

## Required Source

Use the filtered FICTURE PNG generated by the existing FICTURE folder workflow:

```text
pixel-level cell type image/visiumhd_exp1_hex12_k12/hex_12.k12.pixel.png
```

The local evidence that this source is filtered is in:

```text
pixel-level cell type image/Ficture.md
```

Required lines:

```text
--in-sge ${DATADIR}/square_002um/filtered_feature_bc_matrix
--exclude-feature-regex '^(BLANK|NegCon|NegPrb|mt-|MT-|Gm\d+$$)'
```

The official renderer uses all non-black pixels from this filtered PNG after
orientation correction. It does not redraw the map from
`hex_12.k12.results.tsv`.

## Required Coordinate Transform

Use the H&E hires scale exactly as:

```text
scale = tissue_hires_scalef / microns_per_pixel
x_um = ficture_xmin_um + oriented_png_row * 2.0
y_um = ficture_ymin_um + oriented_png_col * 2.0
he_x = y_um / microns_per_pixel * tissue_hires_scalef
he_y = x_um / microns_per_pixel * tissue_hires_scalef
```

Current constants:

```text
microns_per_pixel = 0.2737554241192739
tissue_hires_scalef = 0.13752006
scale = 0.5023464300019976
ficture_xmin_um = -10.934
ficture_ymin_um = -156.145
```

No manual `dx`/`dy` shift is allowed. No full-canvas resize or ROI-size
substitution is allowed.

## Required Orientation

Apply:

```text
np.fliplr(raw_filtered_png)
```

The official summary must show that `fliplr` is the best orientation in the
8-way QC test. The current checked run has `fliplr` as the best orientation,
with 1 px dilated Dice `0.9852059743889615` against the coordinate-reference
mask.

## Required Dimensions

The output canvas must match H&E exactly:

```text
source filtered PNG: 3269 x 3350
H&E hires canvas:    3524 x 6000
official FICTURE:    3524 x 6000
official overlay:    3524 x 6000
```

Do not use a cropped ROI as the official full-canvas FICTURE source. Downstream
candidate-pool jobs may crop from the official full-canvas output only after
passing these checks.

## Required Background Check

The official renderer estimates the H&E tissue foreground and clips colored
FICTURE pixels to tissue. The current checked run has:

```text
source_nonblack_pixels = 6459366
mapped_valid_pixels = 6459366
mapped_inside_tissue_pixels_kept = 6457387
rendered_background_false_color_fraction = 0.0
```

Visible tile seams from the filtered PNG render are handled only by filling
detected internal 1 px empty seam rows/columns from immediate colored neighbors.
This does not change scale, source, orientation, or coordinates.

## Not Official

Do not report downstream results based on these paths as final:

```text
output/visium_hd_exp1/ficture_coord_scaled_hires_continuous_candidate_pool_input_roi
output/visium_hd_exp1/ficture_corrected_candidate_pool_input_roi
output/visium_hd_exp1/agent_verified_filtered_ficture_he_align/strict_results_coordinates_no_shift
```

They can be used only as historical/debug references. The strict
results-coordinate map is allowed only for orientation/Dice QC, not as the
filtered FICTURE source.

## Reporting Checklist

Before showing a figure or metric, verify all of the following in
`summary_official.json`:

1. `status == PASS_OFFICIAL`
2. `uses_filtered_png_source == true`
3. `ficture_md_says_filtered_feature_bc_matrix == true`
4. `orientation_selected_fliplr == true`
5. `orientation_qc_best_is_fliplr == true`
6. `no_manual_shift == true`
7. `full_canvas_matches_he == true`
8. `formula_uses_microns_per_pixel_and_tissue_hires_scalef == true`
9. `background_false_color_fraction_zero == true`

If any check fails, regenerate the official FICTURE output before submitting or
reporting downstream candidate-pool, ranking, or VLM results.
