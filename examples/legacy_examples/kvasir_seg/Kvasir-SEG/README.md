## Kvasir-SEG In This Repo

`Kvasir-SEG/` is kept here as local example data for smoke tests and demos.

It is not the current spatial transcriptomics target dataset.

The current single-image inference target is:

- `data/spatialLIBD/151673/151673_full_image.tif`

The current text prompts are the seven dorsolateral prefrontal cortex layer prompts used for `spatialLIBD` inference.
